ISS Spotter
Overview

ISS Spotter is a web-based visualisation project that tracks the real-time location of the International Space Station (ISS) on a world map.

The application retrieves live ISS position data from an online API and displays the station's current location using an animated icon. The ISS position is updated automatically every 5 seconds and moves smoothly across the map.

Features
Real-time ISS tracking
Interactive world map display
Automatic position updates every 5 seconds
Smooth animation between locations
Displays current latitude and longitude coordinates
Built using HTML, JavaScript, CreateJS, and Adobe Animate
Technologies Used
HTML5
JavaScript
CreateJS
Adobe Animate
Open Notify ISS API
AllOrigins CORS Proxy
How It Works
The application loads a world map.
It requests the latest ISS coordinates from the Open Notify API.
Latitude and longitude values are converted into X-Y coordinates on the map.
The ISS icon is animated to the new position.
The process repeats every 5 seconds to provide live tracking.
